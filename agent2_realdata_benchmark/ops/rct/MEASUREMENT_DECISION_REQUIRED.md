# Study measurement decision — REQUIRED BEFORE FINAL FREEZE

The existing trial has 6 questionnaire prompts **written as temporary rehearsal fixtures** with five 1–5 agreement options. **They are not NASA-TLX** and have no demonstrated psychometric validity. The live release gate intentionally blocks them.

## Decide the construct first

**Option A — Perceived task workload:** implement **NASA-TLX / Raw TLX** according to NASA documentation. The six dimensions are Mental Demand, Physical Demand, Temporal Demand, Performance, Effort and Frustration. The usual NASA-TLX ratings use a 0–100 scale with defined anchors and performance direction; **the original weighted NASA-TLX** additionally performs 15 pairwise comparisons to derive individual weights, whereas an explicitly labeled **Raw TLX** uses an unweighted mean. Decide between these variants and specify version, wording, instructions, timing, endpoints, administration locale, scoring, and missing-data rules. Do not call Raw TLX the weighted NASA-TLX or a direct fatigue measure. Existing Flask code accepts only six integer values in 1..5, so this requires an additive schema/response/UI change and new tests; no live-study result can be interpreted before that change and protocol freeze.

**Option B — Fatigue specifically:** select an appropriately validated subjective *fatigue* instrument for repeated sessions, including its recall window, licensing/permission, validated language, response anchors, dimensionality and scoring. The six existing temporary prompts must not be rebranded as such. A different number of items or a different response scale requires modifying the content validation, UI, response schema, and exports. Fatigue is not interchangeable with sleepiness, mental effort or workload.

**Option C — Both outcomes:** specify one primary construct and one secondary outcome to avoid unplanned multiple-testing claims. Each instrument needs its own properly implemented response/scoring procedure and independent review.

## Review/engineering specification to freeze

- Source title / version / DOI or institutional publisher URL; English/French official or validated translation.
- Measured construct and why it is relevant to the trial's causal question.
- Question wording and legally appropriate reuse; scale endpoints and orientation.
- Number of questions; per-session administration order; device interaction; accessibility.
- Raw data format; numeric range; item-level provenance; computed score; missing-value handling.
- Pre-registered outcome roles, subgroup checks and planned analysis of incomplete sessions.
- Reviewer and review evidence (not generated by code); new candidate fingerprint; complete rehearsal.
